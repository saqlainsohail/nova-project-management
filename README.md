# NOVA – Project Management Application

NOVA is a full-stack project management platform designed to help teams create projects, manage tasks, collaborate with team members, and track project progress.

## 🚀 Features

- User Registration & Login
- JWT Authentication
- Project Creation & Management
- Task Creation & Management
- Task Status Tracking
- Task Priority Management
- Project Progress Tracking
- Team Workspace
- Responsive Dashboard
- MongoDB Database Integration

## 🛠️ Tech Stack

### Frontend
- React.js
- Vite
- JavaScript
- CSS

### Backend
- Node.js
- Express.js
- JWT Authentication
- bcrypt.js

### Database
- MongoDB
- Mongoose
